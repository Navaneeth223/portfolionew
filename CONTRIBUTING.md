# Contributing to Navaneeth KV's Portfolio

Thank you for taking an interest in contributing to this project!

## Code of Conduct

Please maintain a respectful, collaborative, and constructive environment when interacting with this repository.

## Development Workflow

1. **Fork & Clone**:
   ```bash
   git clone https://github.com/YourUsername/portfolionew.git
   cd portfolionew
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Local Server**:
   ```bash
   npm run dev
   ```

4. **Code Style & Formatting**:
   - Ensure all code strictly follows TypeScript type checks.
   - Run `npm run build` locally to verify zero compilation errors.
   - Maintain typography rules (Bricolage Grotesque, IBM Plex Sans, JetBrains Mono — strictly no Inter font).
   - Enforce color tokens (`#0B0D0A` background, `#7CFF9E` signal green accent).

5. **Submitting Pull Requests**:
   - Create a feature branch (`git checkout -b feature/your-feature`).
   - Commit your changes with clear messages (`git commit -m "feat: add your feature"`).
   - Push to your branch and open a Pull Request against `main`.

Thank you for contributing!
